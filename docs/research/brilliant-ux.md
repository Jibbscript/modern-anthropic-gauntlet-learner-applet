# Brilliant iOS design research (reference)

Collected 2026-10-05 by a research agent from Brilliant's live web token sheet, production Rive files, App Store screenshots, Brilliant blog videos, release notes and case studies. Gauntlet evokes this interaction language with its own name, mascot-free visuals and original art; it does not use Brilliant's logos, fonts, mascot or artwork.

## Summary

Brilliant's 2023–2026 design language, reconstructed mainly from primary artifacts I pulled on 2026-10-05. I extracted the live brilliant.org Panda-CSS token sheet and JS bundles (the lesson and onboarding web code includes a WKWebView "Fancy Bridge" for iOS). I also rendered Brilliant's production Rive files locally, sampled pixels from current App Store screenshots and Brilliant's own blog videos, read the help center, Rive/ustwo case studies and the Android release notes, and drove the logged-out onboarding and course-path pages in a headless browser.

Timeline:
- May 2022: streaks and a Home screen added (Android 7.1.0).
- Early 2023: the "game mechanics" redesign, built in Rive. It added a lightning-bolt streak and colour-coded path nodes; the mascots were then "Blorbs", and ustwo did the "Game Feel" North Star work.
- Oct–Dec 2023: course overview, chapter-finish animations and Home redesigned.
- May 2024 (v8.0): "New colors… New designs… New mascot! Meet Koji".
- Late May 2026: Koji relaunched as an AI tutor. The current app (v10.4.x, Sep 2026) is built around Koji.

Visual system:
- Background is white (#FFFFFF), or #141414 in dark mode, with #F8F8F8 / #1E1E1E secondary surfaces and black/white text using alpha tints.
- Two custom typefaces from Contrast Foundry: "CoFo Brilliant", a sans used in weights 400/500/700, and "CoFo Robert", a Clarendon-style slab serif at 500 used only for marketing display text. Math is set in KaTeX_Main and code in Source Code Pro / CoFo Semi Mono.
- Ten 11-step hue ramps (blue, purple, green, red, orange, yellow, pear, papaya, teal, mint, plus cyan/gray). Each subject gets one hue: Math blue #456DFF, CS/AI purple #9D62FF, Data orange #FF8D23, Science yellow #F7C325.
- Pill-shaped "Button3D" with a 4px solid bottom edge. The face sits translateY(-4px) and drops flat on press over 100ms ease-out. The default CTA is #383838 with a black edge; colour variants use hue-500 with a hue-600 edge.

Lesson player:
- One problem per screen inside a light-gray card, with "Start over" under the problem and a full-width "Check" CTA (disabled = 5% black fill, 20% black text).
- Correct: a full-width green banner (#D4F5DD) with a party-popper icon, "Correct!", "+15 XP", "Why?" and a green "Continue".
- Wrong but retryable: a yellow state (#FCE49D, "Try again!" / "Not quite.") with "Get help" plus a yellow "Try again" 3D button.
- Final incorrect: neutral gray (#E5E5E5), deliberately not red. Wrong answers shake horizontally.
- Koji (a green-to-lime four-lobed blob with a single square eye) speaks first on each page and reacts in Rive states (idle, thinking, speaking with glow, correct, wrong, celebration). Copy rules: never give the answer, never say "no worries".

Course path:
- A vertical, gently zig-zagging column of isometric 3D "puck" nodes about 164px apart, under sticky "LEVEL N" header cards.
- Unstarted nodes are gray; completed nodes take the course hue with a white check; the current node is a glowing concentric-ring portal with Koji hovering above it. Locked nodes show an iridescent padlock, level reviews are gear-shaped, and practice nodes show a dumbbell.

Gamification:
- Streak icon is a lightning bolt, filled chartreuse "pear" #D8E82E. A day counts after 3 problems or 1 lesson.
- The week calendar uses filled circles. "Streak Charges" work like streak freezes: shown as batteries, maximum 2, auto-applied.
- XP is earned per correct problem (+15 XP is typical).
- Weekly Leagues: 30 learners, 10 element-named tiers from Hydrogen to Einsteinium, unlock at 175 XP, reset Monday 03:00 UTC. Rows get green/red promotion and demotion zones and gold/silver/bronze rank chips.
- Free users get daily "keys" that unlock lessons. Levels have level checks and level reviews, and mastery is shown with gems.
- End-of-lesson sequence is all Rive: Koji portal flip, XP starburst of green four-point sparkles with a counter pulse, a streak bolt that charges and bursts, league badge promote/demote, and practice nudges.

The habit loop: personalized onboarding (goal, daily minutes, habit time, diagnostic) leads to a daily plan card on Home. Then a short session with instant feedback and XP, a celebratory end-of-lesson sequence, the streak plus weekly league pressure, streak forgiveness (charges and a free "mysterious hero" save), the iOS widget and notifications, and scarcity via keys.

## Notes and recommended tokens

CAVEATS
1) Most hex and size values come from Brilliant's live web token sheet and JS (Panda CSS, retrieved 2026-10-05). Hashed chunk URLs (e.g. /_next/static/chunks/190ig9a3gdgiy.css) can rotate; re-find them from https://brilliant.org/.
2) iOS-specific claims rely on three things: the web bundle's WKWebView "Fancy Bridge" (lesson.ready / nux.ready events), current App Store screenshots and blog videos. The native iOS Home/Leagues tabs could not be captured without an account, so those details come from web components (medium confidence).
3) The lesson player is reconstructed from Brilliant's own videos (Nov 2024–May 2026) and App Store art, not a live session. Video pixel samples are slightly off from the tokens due to compression (e.g. #23C44B vs token #29CC57); prefer the tokens.
4) Several mid-2024–2026 Android release notes are generic ("Bug fixes…").
5) Conflicting or wrong third-party claims:
   - webdesignhot.com says coral #fc6e51 on near-black with "Brilliant Sans". Wrong per live CSS.
   - A WebFetch summary of the Hackernoon review attributed a "Candy Crush path" and "top 7 promoted" to Brilliant. Those lines are about Duolingo.
   - The task brief suggested leagues arrived in 2024; evidence says they existed before the 2023 Game Feel work.
6) Not found (don't invent): haptic patterns, exact retry count before reveal, exact XP table, leagues launch date, an achievements system.

COMPONENT RECIPES
- Button3D: .face{border-radius:var(--r-pill);padding:var(--btn-pad);font:500 16px/1.25 var(--font-ui);background:var(--hue-500);color:#fff;box-shadow:0 var(--press-depth) 0 0 var(--hue-600);transform:translateY(calc(-1*var(--press-depth)));transition:transform var(--press-dur) var(--press-ease),box-shadow var(--press-dur) var(--press-ease)}. In :active, disabled or loading: box-shadow:none and transform:none. Disabled: bg var(--disabled-bg), text var(--text-disabled).
- Feedback bar: full-width, fixed at bottom, ~88px tall, radius 0 or top 16px. Correct = --fb-correct, emoji/illustration, bold 'Correct!', XP chip, 'Why?' secondary pill, hue-green Continue. Retry = --fb-retry, 'Not quite.' / 'Try again!', 'Get help' gray and yellow 'Try again' (yellow-500 face, yellow-700 edge, yellow-900 text). Final miss = --fb-incorrect (neutral; red only on tiny icons) plus explanation.
- Wrong answer: shakeX 9px decaying over ~400ms; no harsh red. Correct: placed tiles turn 2px green-500 borders with green text.
- Path: 92×56 isometric pucks. Gray = not started, hue + check = done, hue concentric glowing rings + mascot = current, gear shape = level review, padlock = locked. Sticky level header with hue-400 2px border and 4px hue-400 bottom edge.
- Streak: rounded lightning bolt in --pear-500, week row of 48px circles, battery icon for freezes. End-of-lesson: bolt scales 1.2→0.9→1.05→1, then days bounce/ripple and pear diamond particles burst.
